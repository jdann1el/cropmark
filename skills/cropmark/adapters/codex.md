# Codex adapter

Use the tools actually exposed in this session. Native image generation, when available, creates/edits conceptual bitmap assets; local HTML/Pillow handles controlled composition and type. Inspect local PNGs with the image viewer. Read the relevant engine README for runtime requirements; report a missing dependency instead of claiming a check ran.

Follow the same concept/sketch/review stages on different Codex models. Do not infer effort from speed or output style. If effort is exposed, record it for an experiment; ordinary use preserves the user's configured model. Local records can carry stage outputs across short contexts. Use supplied assets or an honest typographic route when generation/network is absent.

No external model API, JEV or extra decision provider is needed by Cropmark. The repository's controlled evaluation fixes tools/fonts/assets per condition; that restriction is an experiment boundary, not a ban on tools the actual user authorizes.
