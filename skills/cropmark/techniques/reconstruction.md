# Faithful editable reconstruction

The supplied reference is the target, not a moodboard. Preserve copy, order, composition, scale, colour, typography and identity; do not impose another style or a word cap. Identify editable elements and which photographic base the brief permits reusing.

1. Measure the canvas and major anchors. Transcribe all supplied copy and inventory the reusable assets. Keep the full reference outside final render layers.
2. Rebuild type and shapes as separate elements. For physical panels, apply the same planar transform to text and its associated surface; preserve perspective, light and occlusion. Deliberate HUD text remains in screen coordinates.
3. Compare aligned full-resolution images and feed versions. Review glyph shape, spacing, crop, positions and colour; report approximate matches honestly.
4. Render from the packaged sources in a fresh output directory. Edit one text element and rerender to verify that it is editable and that unrelated content remains intact.

Deliver editable source, assets, fonts or their permitted references, transforms/masks, complete final PNGs and reproduction instructions. Copying the reference PNG is not reconstruction. Reusing an explicitly supplied clean photo is allowed and must be distinguished from recreating that photo.
