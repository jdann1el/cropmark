# Carousel system
1. Plan first: `NN / role / headline / body / visual anchor / recipe`. Roles: cover hook, problem, point(s), proof, breather, recap, CTA.
2. Cover = standalone post: one claim, one strong visual, swipe cue.
3. Every interior slide has a visual anchor ≥25% of the slide (cutout, giant numeral, photo strip, brand shape, icon-scale illustration). "Text on empty colour" is the #1 baseline failure.
4. Continuity: same margins, type pair, palette; page counter; a motif crossing slide borders (panorama) or a repeating corner mark.
5. Rhythm: alternate dense/light; never two full-bleed photos in a row; vary layouts (no identical structure twice in a row).
6. CTA slide: echo the cover visually, one real action (save/share/follow), person or brand photo if available.
7. Render as one wide HTML canvas (N×1080) when using panorama; set `data-slices="N"` on the frame and render.mjs slices it.
8. QA: contact sheet of all slides at 360 px each; check the set reads as one family and each slide alone.
