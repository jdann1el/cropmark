# Story in one frame
Test: cover the text — can a stranger say what it's about? If not, the image is decoration.
1. Write the story as "X + Y = tension": subject + object + stake (masked driver + muscle car + police lights; tired student + 3 a.m. clock + coffee mountain).
2. Choose the device: contrast (split), stakes stack (fg/mg/bg), absurd placement (object where it shouldn't be), aftermath (wreck behind, mess left), duel (two products face to face), reveal (blurred/hidden thing).
3. Faces: one emotion pushed one notch past natural, eyes sharp, gaze to camera or to the object.
4. Depth: foreground element cut by the frame edge makes it feel close; background tells context; keep the mid-ground hero sharp.
5. One accent colour that belongs to the story (police red/blue, money green, warning orange).
6. Text, if any, names the stake in ≤4 words the image can't (time, price, outcome question) — never what the image already shows.
Niche starters: car/vlog → stakes stack · horror → single light source + silhouette + empty doorway, 0-3 words · cooking → hands + steam + the hero dish huge, one sensory word · tech duel → two products, cheap one "winning" · finance → UI hero · tutorials → hands on tool + tape label.
