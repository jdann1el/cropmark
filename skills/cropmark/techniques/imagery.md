# Imagery (generated or sourced)
- Order of preference: client's real photos/product > free stock (Unsplash/Pexels, keep source URL) > AI generation.
- Generated images: NO text, letters, logos, signs, UI, watermarks. Ask for the quiet zone explicitly ("empty sky in the upper third", "clean wall on the left 40%").
- Prompt skeleton: medium (hyperreal photo / studio product shot / architectural photo) + subject + action + setting + lighting + lens/depth + grade + composition (where the subject sits, where the quiet zone is) + "no text".
- Exaggerate differences for before/after; models make them too subtle.
- Cutouts: generate on a flat background whose colour is NOT in the subject (magenta for green objects, green only for non-green/non-chrome subjects). Use the generator's built-in transparent background if it has one, else `cm.key_out` + `cm.despill`. rembg if installed.
- Glass, liquids, chrome, smoke and hair key badly: generate them directly on the final background/colour field instead of cutting them out.
- Generator output is often ~1-1.4 MP (e.g. 1376x768, 928x1152): plan crops so the hero isn't upscaled >1.5x; regenerate with the subject larger rather than upscaling.
- Grade in the engine for consistency across a set (same contrast/saturation/temperature curve).
- Check every generation for AI artefacts (hands, text-like squiggles, warped logos, duplicated objects) at 100 % before using it.
- Faces generated by AI are mock-ups; label them as samples for client work.
