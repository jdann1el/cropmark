# Independent visual critique

For substantial original work or redesign, obtain a fresh visual critique of the representative before expanding the set when native delegation is available and authorized. Use the existing agent environment; do not configure another model API. Without delegation, perform a separate viewer pass and mark it as self-review. The critique informs correction and never substitutes for required human acceptance.

Give the critic the raw brief, representative full/feed PNGs, the inspected close reference images and credits, and any supplied identity asset. Withhold the producer's rationale, self-scores, proposed fix and completion claims. The critic may inspect actual bounds/source assets when needed; do not provide an intended answer. Ask it to assess the artifact as a viewer/client against the real reference at the same display size.

Use this bounded review request:

> Inspect these actual images before explaining them. What is recognised first; what makes the message/product/story attractive or convincing; does the title/image relationship support that promise? Compare typography, grouping, image framing/material, brand role and finish with the supplied comparator. Name the three most consequential visible differences with image/region and audience consequence. Separate observation from taste preference and uncertainty. Check required copy/identity survival. Report three separate findings: content/identity integrity; functional composition/readability; and comparative appeal/specificity. For the last, identify the visible reason to care about this particular message/product, and whether it sustains the intended reference level; mark that judgment provisional or unverified when appropriate. Then return `ready for set extension`, `needs correction`, or `unverified`, with the concrete evidence. Extension readiness must say which findings it covers; absence of clipping or collisions alone does not establish appeal. Do not infer approval from clean geometry, invent a defect to fill a list, award a self-score, or assume every reference is perfect.

Preserve the verdict and the actual images. If consequential weaknesses remain, spend the next available correction on the leading cause and re-inspect. Do not convert the criticism into a justification for the existing layout. A critic's stylistic preference is not a universal rule, and a favorable verdict is not release approval. At the three-round limit, stop and disclose unresolved gaps.

Write an explicit status for each finding: integrity, function and comparative appeal. When only the first two are supported, record `function ready / appeal unverified`; leave extension readiness unverified rather than compressing this into an overall `ready`. For type-led work, judge the visible silhouette, density and relationships before reading its explanation. Naming a gap “pause” or placing an isolated paragraph on a mathematical axis does not show that it is convincing. In supplied human calibration, retain disagreement between critic and human as a review limitation; do not rewrite an earlier favorable verdict or treat a prompt revision as evidence that it is fixed.
