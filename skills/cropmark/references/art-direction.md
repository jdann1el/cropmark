# Art direction

## 1. Ground the idea
Finish with a compact contract: required message/copy; viewer; intended response; real assets and identity; count/size; permitted changes. Separate facts from sample content. Inventory five to ten concrete things belonging to this subject: an object, gesture, material, constraint, ritual, place, product feature or contrast. If essential facts are absent, choose a concept that does not fabricate them.

## 2. Read references as decisions
Choose two to four pertinent entries from `../refs/atlas.md`, open the actual images when available, and name the useful mechanism. Separate what was observed from what was inferred. Search the subject's objects and world, not just its industry. Borrow a relationship (scale, framing, type interacting with an object), then supply this brief's idea and content. If the images cannot be inspected, mark the reference unverified and work from an inspected alternative or the brief.

## 3. Diverge, then compare
Write three short concept sentences, each linking message → visible device → audience response. Run the competitor test: if replacing the name leaves the idea equally valid, find a more specific subject detail. This is diagnostic, not a requirement that no other brand could ever use a technique.

Render the strongest two as rough visual compositions using available assets, real headline length and realistic type. Compare at feed size: what reads first; what story is visible; what distinguishes the subject; whether the assets can sustain the intended finish. Colour swaps are one concept. Select for fit, hierarchy, distinctiveness and feasible craft, then retain a one-line rejection reason for the alternative. Show routes and wait only if the user asks to select.

## 4. Develop before expanding
Resolve the representative piece: largest mass, image/type relationship, actual font files and breaks, colour roles, margins and spacing. For a carousel, resolve cover plus the most demanding interior slide, with the full sequence mapped. For a campaign, resolve one hero and one contrasting role. Revisit a direction that only works with imaginary assets.

## 5. Inspect and correct
Use `../qa/checklist.md` and `visual-rules.md` on full-size and feed renders. Fix idea first, then hierarchy/composition, type, imagery and detail. A weak concept can be replaced within the three-round allowance; cosmetic polishing does not repair an empty premise. Stop early when no relevant observed defect remains. A self-score alone is not that observation.

## Short route
For a narrow edit: state the requested change and invariants, edit, inspect the changed region plus the full set. For faithful reconstruction: the reference provides the direction; measure its relationships, preserve required identity/copy and validate fidelity separately. Do not force novelty, extra photos or new type into an approved design.
