# Other formats
- **Story / Reel cover 9:16 (1080x1920)**: keep text out of top 270 px and bottom 380 px (Stories) / bottom 35% + right 120 px (Reels). Hook in the vertical middle (grid crops to 3:4). Feed test 360 px.
- **X / LinkedIn landscape**: 1600x900 (X), 1200x627 (link preview). X also shows 4:5 uncropped — prefer it for impact. Margins ≥64 px, headline left/centre-left.
- **Square 1:1 (1080x1080)**: write a shorter title; never crop a portrait layout into a square.
Same principles as post.md; v1 of this skill tests only thumbnails, posts and carousels.
