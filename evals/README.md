# Evals
- `briefs.md`: 12 frozen briefs (5 thumbnails, 4 posts, 3 carousels). `holdout.md`: 5 unseen briefs.
- Method: same briefs made without the skill (baseline) and with it; blind A/B + rubric (qa/rubric.md).
